# Havello Games

A cyberpunk-styled landing page for a game studio. Single HTML file, no build step, no framework.

## Live

https://lemuelowusuansah.github.io/havello/

## Features

- Cyberpunk aesthetic with dual background layers, filters, and scan lines
- Hero section, game showcase, about, and footer
- Google Fonts (Space Grotesk)
- Font Awesome icons via CDN
- Fully responsive
- Single-file — entire site in `index.html`

## Notes

- Background images are loaded from Unsplash CDN. They may change or break over time; self-host if you fork.
- Social links are placeholders (`#`).

## Run locally

Open `index.html` in a browser. No install, no server.

Or serve it:

    python3 -m http.server 8000

Then open http://localhost:8000.

## Stack

Plain HTML, CSS. No build step, no dependencies.
